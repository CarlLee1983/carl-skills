可以單獨裝的agent 技能

Carl 維護的開源 agent skills，提供可重複使用的工作流程。每個技能是一個自足的目錄，Codex 與 Claude Code 都能裝，只裝需要的那一個。

npx skills add CarlLee1983/carl-skills --list

列出可安裝的技能，不會安裝。需要 Node.js 與 npm；完整安裝方式見 README。

五個技能

  1. design-experience以產品設計師的角色，從主題、既有功能或不滿意的現有介面出發：訪談、比較設計方向、建立互動原型，依回饋收斂到定稿與交接。Codex、Claude Code 等
  2. devops軟體交付與維運的統一入口：環境、CI、發布評估、部署與回復、監控、事故、備份還原。先取得證據，在明確授權內執行並核驗。Codex、Claude Code 等
  3. humanize-writing潤飾繁體中文與英文，減少制式語句，保留原文的事實、立場與語氣；敘事段落另有保留情節與節奏的規則。Codex、Claude Code 等
  4. pm專案經理能力：範圍與計畫稽核、進度與依賴、下一步、風險與假設、變更影響、進度報告與結案。附實測邊界案例。Codex、Claude Code 等
  5. calibrate-codex把明確回饋或重複出現的問題，轉成範圍適當的指引、技能、hook、規則或驗證措施。Codex 專用

看它實際交出什麼

design-experience 是這裡的設計技能。說得再好，不如看成品：三個案例一回合一回合攤開：使用者說了什麼、技能怎麼判斷、原型長什麼樣，以及哪些驗證做了、哪些沒做。其中一個案例記錄了技能本身被改過一次。

看它如何守住邊界

pm 是專案經理技能。一般 Agent 常把「看進度」誤當成「執行授權」，或者缺少資料時隨意捏造上線日期。pm 預設唯讀、以三級證據分級（verified、inferred、assumed）標明推論，交接嚴格遵循專案規則。三個案例，檢驗 35+ 個行為情境。
