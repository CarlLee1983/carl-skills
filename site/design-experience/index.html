先問清楚，再畫出來：design-experience 案例

design-experience 讓 agent 當產品設計師：訪談、比較方向、做出能操作的原型，你說定稿才交接。八個案例，從設計判斷到能操作的原型，分清驗證與假設。

看八個案例

它不先畫畫面，先問誰會用、卡在哪， 端出幾個真的不同的方向讓你選， 你說定稿才交接。

案例頁附上可操作原型，多數是單檔離線 HTML；Threadnote、序間與泊光要連同相鄰資料夾的樣式、腳本及圖像等資產一起下載，才能離線開啟。畫面裡的訂單、顧客、作品與回饋全是示例資料。

看你手上有什麼

進入模式只看兩件事：有沒有介面，有沒有固定的視覺來源（品牌、設計系統、tokens）。模式決定先比視覺還是先比結構。

  1. 主題起手

    沒有介面，也沒有視覺來源。先訪談風格，在同一個暫定版型上用三張 style tile 定視覺，再比結構。案例是接案插畫家的個人官網。

  2. 功能起手

    已經有介面或固定的視覺來源，要為還沒有介面的能力做設計。先把能力整理成使用者任務，直接比結構，再處理視覺。案例是 dbcli 的稽核紀錄審查。

  3. 改善

    已經有介面，但用起來不對。先診斷問題、重新框定這頁在做的工作，再提出野心不同的方向。案例是商家後台的訂單頁，跑了兩輪。

再看你帶了什麼來

你貼的圖或網址是參考來源，疊在上面任一種起手上，不另成一種模式。技能看你想拿它做什麼，不看它是圖還是網址；判斷不出來時，先寫下它的理解讓你改。

  1. 目標稿

    「想做成這樣」，多半是一張 AI 生成的 UI 圖。不照抄：先逐區審查缺少的能力、生成瑕疵與品味問題，每項決定照做、改做法、刪除或待產品決定，再做成原型和原圖並排。案例是寵物美容店的預約網站。

  2. 參考網站

    「喜歡這個網站的設計」。拆成 5–8 個屬性，請你逐項標「要／不要／無所謂」，再用採用程度不同的視覺處理和它並排比較。只借特質，不搬對方的 logo、圖像、文案與品牌配色。案例是同一家店借花藝工作室的網站。

哪些是真的，哪些沒驗過

案例性質驗證過沒有驗證
訂單頁腳本試跑兩輪。使用者回覆取自腳本，沒有真人參與；後台是虛構重建。Playwright 截圖逐張檢視（兩輪共 63 張）；腳本化互動斷言，定稿 22／22 通過。真實客服試用、讀屏器、Safari 與 Firefox、實機手機、色覺差異模擬。
dbcli實際試跑，在公開 repo 上進行。agent 依技能執行，使用者不在場，每個選擇點都接受建議。32 張截圖逐張檢視後修了七處；程式化操作驗證 9 件待審、18,412 列合計、鍵盤與 390 寬的清單／詳情切換。真人試用，所以「三分鐘內找出」還沒有答案；螢幕報讀器、Safari 與 Firefox；用 dbcli 實際產生的稽核檔驗證欄位。
個人官網腳本試跑。使用者回覆取自腳本；作品圖是 SVG 濾鏡做的佔位圖。三次點擊路徑、表單錯誤與失敗、390 寬溢出、鍵盤焦點，都用 Playwright 檢查。真人試用、讀屏器、Safari 與 Firefox、Windows 字型、真實作品圖。
照著生成圖做預約網站腳本試跑。使用者回覆取自腳本，沒有真人；目標稿是本機 HTML 渲染、刻意埋了瑕疵的 AI 風格圖，店名、服務、價格與時段是虛構示例。主要路徑程式檢查 v1 與 v2 各 32 項全部通過；選完服務後「下一步」按鈕從畫面外（y=985）移到畫面內（y=780）；原型截圖逐張檢視。真人試用，v2 也沒有被重新試用；實機、Safari 與 Firefox、螢幕閱讀器、200% 縮放。
借一個喜歡的網站腳本試跑。使用者回覆取自腳本；被參考的網站是為驗證寫的虛構花藝工作室網站，不是真實公司。定稿原型 57 項斷言在 390 與 1440 寬全部通過；檢查中修了七處；各步驟與狀態截圖逐張檢視。真人試用（使用者沒有回答喜歡與卡住的地方）、實機、螢幕閱讀器、200% 縮放。
讓回饋走到決策真人使用者選定客戶回饋題材與偏好的技能來源；Threadnote 是虛構產品，結構與視覺由代理暫定，尚未定稿。Chrome 檢查桌機與手機的示例流程、搜尋恢復與鍵盤焦點；暫停、離開畫面停止與減少動態通過，五種寬度的動態文字沒有重疊。詳見案例驗證表。真人任務試用、實機、其他瀏覽器與螢幕報讀；未驗證真實整合、產品需求或影片匯出。
企業官網，從理解到諮詢真人使用者選定品牌策略顧問公司，並選擇「從混亂，到清楚」的新版視覺加入案例。序間、作品與服務皆為虛構，圖像由 AI 生成；視覺選擇與真人任務試用分開記錄，詢問沒有寄出資料。新版 Chrome 75 項功能斷言與 69 項動態／降級斷言通過，涵蓋捲動收束、雙向焦點交接、減少動態、案例與詢問恢復；保留原版與對照入口。詳見案例驗證表。真人任務試用、實機、其他瀏覽器與螢幕報讀；未驗證真實商業服務、客戶成果或轉換效果。
沿著光，安心抵達使用者核准海岸旅宿題材；泊光品牌、房型與圖像皆為虛構，結構與視覺由代理選定。本機詢問不會寄出資料。房型、日期詢問、鍵盤、暫停與減少動態的檢查範圍及實際結果，詳見案例驗證表。真人視覺驗收與任務試用、實機、其他瀏覽器與螢幕報讀；沒有真實訂房或旅宿服務驗證。
