2. **判斷**

   `pull_request_target` 搭配 checkout PR head，再執行 `npm test`，將不受信任的 PR 程式碼帶入過度授權的工作。測試需要儲存庫寫入權限的證據為「無此證據」。

   已安裝的 `devops` 描述適合承接 CI 權限修正，但不是底層資安審查技能；沒有找到底層資安技能、以基準做法完成。單獨使用 `pull_request_target` 不構成發現；問題是本案的權限與執行來源組合。

3. **發現**
