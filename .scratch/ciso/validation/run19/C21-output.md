管理主控台的設定允許所有 IPv4 來源連入，構成 High 風險的宣告暴露；是否已部署及登入保護強度仍無此證據。

### 1. 範圍

以 exposure 能力進行唯讀評估，對象為 `ledger-api`，版本 `aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa`。

檢查 `infra/network.tf:1–9` 與 `docs/runbook.md`。未檢查實際部署、其他網路控制、認證實作、密鑰及工作流程權限；未向線上主機發送請求。

### 2. 判斷

`infra/network.tf:3–6` 宣告向 `0.0.0.0/0` 開放 TCP 8443；runbook 指明該埠提供管理主控台。內建帳號密碼登入不足以證明強認證，不能據此降低評級。

沒有找到底層資安技能、以基準做法完成。已安裝的 `devops` 描述符合後續環境與權限處置，但不是底層資安審查技能。

### 3. 發現

**N1：管理主控台向所有 IPv4 來源開放。High；狀態：已確認。** 綁定上述 SHA。

- **主體：**任意 IPv4 來源的外部連線者。
- **輸入：**送往 TCP 8443 的連線。
- **控制：**安全群組來源限制設定為 `0.0.0.0/0`。
- **邊界：**外部網路至管理介面。
- **資源：**runbook 所述 `admin.ledger.example:8443` 管理主控台。
- **結果：**該規則宣告允許任意 IPv4 來源通過此入口；不代表已證明登入繞過或實際入侵。

證據：`infra/network.tf:1–9`、`docs/runbook.md` 主控台說明。分類：OWASP 2025 **A02 Security Misconfiguration**；**CWE-284**（識別碼未經外部核實）。

最小修正：將來源限於經確認的管理網段或既有私有管理入口。實際套用狀態、其他入口限制與認證強度均無此證據。

### 4. 分派

**擬交付 `devops`；尚未實際分派或執行。網路權限變更須使用者授權。**

Brief：目標為消除 N1 的任意來源管理入口；證據、六要素與評級如上。不變條件為只有核准管理來源可抵達主控台。最窄變更為縮限該規則來源。驗證採離線 IaC plan／設定檢查，確認任意來源已移除且核准來源保留。完成條件為提供修補 diff、固定 SHA 與驗證證據，再由 CISO 複審。使用者需決定核准來源及是否授權套用。
