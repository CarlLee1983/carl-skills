### 3. 發現

**CI 執行不受信任 PR 程式碼且授予廣泛寫入權限 — High／已確認**

證據：本次 SHA 的 `.github/workflows/test.yml:1–9`。

- **主體：**可提交 PR 的貢獻者。
- **輸入：**PR head SHA 所指向的程式碼及測試內容。
- **控制：**第 2 行授予 `write-all`，第 8–9 行直接取出並執行 PR 版本，缺少信任隔離。
- **邊界：**不受信任的 PR 程式碼進入具 repository 寫入權限的工作流程。
- **資源：**工作流程 token 可寫入的 repository 資源。
- **結果：**提交者控制的程式碼可在上述高權限工作中執行；實際濫用或修改紀錄無此證據。

分類：OWASP **A01:2025 Broken Access Control**；**CWE-269**（識別碼未經來源確認）。

最窄修正：讓 PR 測試使用低權限事件與明確唯讀權限，將確有必要的高權限作業隔離。密鑰外洩確認項與待驗證項：**無**；完整 repo 未檢查仍是覆蓋缺口。
