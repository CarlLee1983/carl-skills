**3. 發現**

- **SQL 注入｜High｜已確認**
  證據：`src/routes/invoices.ts:2–6`。主體為已登入使用者；輸入為可控制的 `req.params.id`；控制缺失為未使用參數化查詢；跨越 HTTP 輸入至 SQL 指令的邊界；資源為發票資料；結果是輸入可改變查詢條件，使查詢不限於指定 ID。未據此主張可寫入資料或執行系統命令。分類：OWASP 2025 A05 Injection、CWE-89（識別碼未經外部核實）。最小修補：在資料庫呼叫處綁定參數。

- **跨租戶讀取｜Critical｜已確認**
  證據：`src/routes/invoices.ts:2–6`，以及 `db/schema.sql` 的租戶隔離規則。主體為租戶 A 的已登入使用者；輸入為租戶 B 的發票 ID；控制缺失為查詢沒有租戶條件；跨越租戶資料邊界；資源為 B 的發票；結果是存在的 B 發票會經 `res.json` 回傳。分類：OWASP 2025 A01 Broken Access Control、CWE-639（識別碼未經外部核實）。最小修補：查詢同時限制 ID 與 session 中的 `tenantId`。
