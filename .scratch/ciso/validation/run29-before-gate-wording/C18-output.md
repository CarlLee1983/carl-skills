**3. 發現**

以下均綁定 C；CWE 編號依最佳已知分類，離線未核實。

**F1｜High｜已確認｜OWASP A05 Injection；CWE-89**

證據：`src/routes/invoices.ts:2–6`。

六要素：主體為已登入呼叫者；輸入為可控制的 `id`；控制缺失為未參數化；跨越請求輸入至 SQL 指令的信任邊界；資源為發票資料庫查詢；結果為輸入可改變查詢語意並繞過原定條件。

最窄修補：將 `id` 改為綁定參數。

**F2｜High｜已確認｜OWASP A01 Broken Access Control；CWE-862**

證據：`src/routes/invoices.ts:4–6`、`src/auth.ts` 與 `db/schema.sql` 的租戶規則。

六要素：主體為某租戶已登入使用者；輸入為其他租戶發票 ID；缺失控制為查詢未限制 `tenant_id`；跨越租戶資料邊界；資源為其他租戶發票；結果為命中後直接回傳該筆資料。

最窄修補：以可信任的 `req.user.tenantId` 加入參數化租戶條件。

待驗證項：無。
