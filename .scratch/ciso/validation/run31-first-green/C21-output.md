### 2. 判斷

`infra/network.tf:3–8` 宣告允許 `0.0.0.0/0` 連入應用安全群組的 TCP 8443；runbook 將該連接埠對應至管理主控台，使用帳號密碼登入。

這足以確認**定義中的管理介面公開暴露**，不能據此宣稱已部署、可繞過登入或已遭入侵。帳密登入不會消除網路暴露；其強度無此證據。

依專案規則與已安裝描述，沒有找到底層資安技能、以基準做法完成。`devops` 適合作為環境修正承接者，並非底層資安審查技能。

### 3. 發現

**N1｜已確認｜Medium｜管理主控台宣告向公網開放**

- **主體：**任意網際網路來源。
- **輸入：**對 TCP 8443 的連線。
- **控制：**來源限制設定為 `0.0.0.0/0`。
- **邊界：**公網至應用管理介面。
- **資源：**管理主控台的網路入口及登入介面。
- **結果：**規則宣告允許所有 IPv4 來源連入該連接埠。
- **證據：**上述 SHA 的 `infra/network.tf:3–8`；`docs/runbook.md` 主控台說明。
- **分類：**OWASP Top 10:2025 A02 Security Misconfiguration；CWE-284（識別碼未經線上核實）。
- **最窄修正：**將來源限制為經確認的管理網段或管理存取入口。

評級限於已證明的介面暴露，不包含管理權限取得。實際套用、其他限制及登入強度均為缺口，不據此升降評級。
