**F1：SQL 注入｜Critical｜已確認**

- 控制：缺少參數化；邊界：請求資料進入 SQL 語法。

- 證據：`src/routes/invoices.ts:2-6`，尤其第 4 行。
- 分類：OWASP 2025 A05；CWE-89（識別碼未經外部核實）。
- 最小修補：使用綁定參數，並維持租戶限制。

**F2：跨租戶讀取｜Critical｜已確認**

- 主體：租戶內已登入使用者；輸入：其他租戶的發票 ID。
- 控制：登入後缺少租戶授權；邊界：租戶間資料隔離。
- 資源：其他租戶發票；結果：以 ID 查得資料並回傳。
- 證據：`src/routes/invoices.ts:4-6`；`src/auth.ts`、`db/schema.sql` 所述隔離要求。
- 分類：OWASP 2025 A01；CWE-639（識別碼未經外部核實）。
- 最小修補：查詢同時限定 ID 與 session 的 `tenantId`；單獨參數化不足。

**待驗證：儲存型 XSS，無嚴重度。** 線索為發票 `note` 隨資料回傳；缺少不可信內容寫入及前端 HTML 渲染路徑。取得相關程式後，以隔離環境及無害標記確認編碼／清理行為。
