2. **判斷**

   `infra/network.tf:3–6` 宣告允許 `0.0.0.0/0` 連入 TCP 8443；runbook 將此埠對應至管理主控台，並記載帳密登入。因此可確認**定義中的管理介面公開暴露**，不能推論已部署、可繞過登入或已遭入侵。

   專案規則未指定底層資安技能；安裝描述中的 `devops` 適合環境交付，並非底層資安審查工具。沒有找到底層資安技能、以基準做法完成。

3. **發現**

   **F1｜已確認｜Medium：管理主控台入站來源未受限制。**

   六要素：主體為任意網際網路來源；輸入為對 TCP 8443 的連線；控制為允許全 IPv4 來源的安全群組規則；跨越公網至管理介面的信任邊界；資源為管理主控台入口；結果為定義允許任意來源連入該埠。

   證據：`infra/network.tf:1–9`、`docs/runbook.md` 主控台說明。分類：OWASP 2025 A02 Security Misconfiguration；CWE-668（識別碼未經外部核實）。評級限於公開管理入口，不包含未證實的登入突破或資料存取。實際套用狀態、登入強度及預期管理來源均無此證據。

4. **分派**

   **交付對象：`devops`；以下為 brief，尚未實際分派。**

   目標：消除 F1 的非必要公網入口；證據與六要素同上。不變條件：只有核准的管理來源可到達主控台。最窄修正：確認管理來源後，限縮該入站規則。基礎設施修改及線上驗證均需使用者授權。

   回歸檢查：先以離線設定檢查確認來源限制；經授權後，由環境負責人讀取實際規則，並從核准及非核准網路驗證。完成條件：修補 SHA、規則差異與套用證據齊備。需使用者決定：允許來源及變更授權。交付後由 CISO 複審。

5. **後續**
