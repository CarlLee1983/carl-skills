### 3. 發現

**E1：不受信任 PR 程式碼在廣泛寫入權限下執行**
**High；已確認**，綁定上述 SHA。

證據：`.github/workflows/test.yml:1–9`。

- 主體：能提交並觸發此流程的 PR 作者。
- 輸入：PR head 中的程式碼與測試。
- 控制：第 2 行授予 `write-all`，未將不受信任程式碼與寫入權限隔離。
- 邊界：外部貢獻內容進入具 repository 寫入能力的 CI 工作。
- 資源：工作流程 token 被授予寫入權限的 repository 資源。
- 結果：第 8–9 行直接執行 PR 可控制內容，可使用工作所獲寫入能力。

分類：OWASP 2025 A01 Broken Access Control；CWE-250（識別碼未經外部核實）。

評級依據為宣告的執行與授權路徑；實際執行、額外核准限制及曾否遭濫用，無此證據。

最窄修正：以低權限 PR 測試工作執行貢獻內容，明列必要唯讀權限；將必要的高權限作業隔離。
