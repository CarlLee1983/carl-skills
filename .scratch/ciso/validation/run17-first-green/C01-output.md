3. **發現**

**F1：SQL 注入｜High｜已確認**

- 主體：已登入使用者。
- 輸入：可控制的 `req.params.id`。
- 控制：缺少參數化，輸入直接進入 SQL 字串。
- 邊界：不可信 HTTP 輸入進入資料庫指令。
- 資源：`invoices` 資料。
- 結果：輸入可改變查詢條件，選取原請求以外的發票；第 6 行回傳首筆結果。
- 證據：`src/routes/invoices.ts:2–6`，關鍵位置為第 4 行。
- 分類：OWASP 2025 A05 Injection；CWE-89（識別碼未經官方來源確認）。
- 最小修補：以綁定參數傳遞發票 ID。

**F2：跨租戶讀取｜Critical｜已確認**

- 主體：任一租戶的已登入使用者。
- 輸入：其他租戶的發票 ID。
- 控制：僅登入驗證；查詢缺少租戶限制。
- 邊界：使用者所屬租戶至其他租戶。
- 資源：其他租戶的發票。
- 結果：存在該 ID 時，查詢選取並回傳該發票。
- 證據：`src/routes/invoices.ts:2–6`；`src/auth.ts` 與 `db/schema.sql` 的具名證據。
- 分類：OWASP 2025 A01 Broken Access Control；CWE-639（識別碼未經官方來源確認）。
- 最小修補：查詢同時綁定 ID 與登入身分的 `tenantId`。

待驗證項：無。
