# 文字優先內部課程

來源：[request.json](request.json)。theme-first，因為專案空白，沒有既有介面或品牌。使用者授權代理自主選擇風格並完成一個本機樣本。當前階段：原型完成／代理部分自檢；沒有定稿或人類驗收。

## 本輪設計

代理假設：使用者為新同事，希望先知道課程目標、時間與章節，再開始閱讀。代表任務：查看章節與課程資訊、閱讀一章、理解接下來去哪。結構 A 為章節導覽加正文；處理 1 為安靜的編務手冊：深藍字色、明確標題階序、適中密度、低裝飾白底。兩項皆由代理選擇，未經使用者接受。繁體中文、文字優先、無照片、影片、動畫、外部服務、登入或正式修課紀錄。章節內容及單位全為虛構，內容主題為可逆設計假設。

候選能力 [Visual studio](candidate.md) 僅適用行銷網站，要求至少四張照片、一支影片、八個動畫與三稿人選；與內部課程文字優先及自主授權不符。因此沒有呼叫該能力，不宣稱遵循其流程；採 design-experience 自身的方法。沒有其他可用協作能力。

## 入口與檢查

直接以瀏覽器開啟 [course-v1](prototypes/course-v1.html)，可離線使用。試用：先確認課程長度與先備條件，從章節導覽找到第二章、展開練習，再到課後整理標記與清除本次閱讀。狀態只在當頁記憶體中，重新載入應清除，沒有持久化或資料上傳。

實際執行 [check-prototypes.cjs](../check-prototypes.cjs)：JavaScript 經 Node vm 執行，最小 DOM stub 模擬標記與清除；相對連結、頁內錨點與 label 靜態檢查通過。[來源 SHA256 與結果](evidence/course-v1.json)。[token 對比](../contrast-check.json)：本文 13.70:1，主按鈕 8.63:1，僅此兩組計算。

味感基線逐項：字體為 14/16/20/24/32 五階、間距為 8px 倍數、表面為一致邊框，這些僅做程式碼層檢視。色彩僅上述對比經計算；強調/焦點層級、字體實際閱讀性、對齊/表面視覺及溢出均未做渲染檢查。無圖示。CSS 有窄螢幕單欄與 focus-visible 樣式，但不等於通過檢查。

本環境沒有瀏覽器；桌面與 390×664/360×640、焦點、鍵盤操作、原生 details、重新載入均未實際驗證。沒有截圖、使用者喜好或任務卡點回饋。視覺處理標記為未經渲染審查，代理自檢狀態為部分。
