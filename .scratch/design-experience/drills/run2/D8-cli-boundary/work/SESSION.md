## 訪談（GUI 概念軌）
- 產品類型（推斷，待確認）：功能型產品／資料工具（依據：查詢、schema、權限分級、匯出、黑名單）。
- 已確定：沒有品牌資產；受眾是團隊新人。
- 第 3 回合「都照建議」，以下全部定案（Q6–Q13）：
  - 受眾與主要動作：團隊新人確認自己在哪個連線、什麼權限下，再安全地查資料。第一個流程是選連線 → 看 schema → 下查詢 → 看結果或匯出。
  - 平台：由 CLI 開啟的本機網頁（例如未來的 `dbcli ui`），桌面寬度 1280 以上，不考慮手機。
  - 語言：繁中介面；SQL、欄位名、指令、錯誤代碼保留英文原文。
  - 淺色與深色都要。
  - 氣質：偏安靜、中等偏密、偏引導、中性偏嚴肅。形容詞是「沉穩、清楚、讓人安心」，要避免的是「炫技」。
  - 使用頻率：一天數次、每次短時間。預設中等密度，只有結果表格提高密度。
  - 一眼必須看到：連線名稱、權限等級（形狀加文字）、被黑名單遮蔽的欄位。
  - CLI 軌：等 GUI 概念選定方向後再做（Q13 a）。
- 訪談完成。
