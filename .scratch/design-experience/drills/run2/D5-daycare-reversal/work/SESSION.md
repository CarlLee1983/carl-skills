## 任務與目標

- 專案材料：`../fixtures/project.md`（後端 API 說明，唯讀）
- 原始需求：「社區托育中心要一個給家長看的網站：每日接送時間、當天活動照片、臨時通知。後端 API 已經有。」
- 進入模式：**主題起手（theme-first）**。依據：只有 Node.js 後端 API，沒有任何前端、品牌、logo 或設計系統（project.md）。

## 已有來源的事實（project.md）

- 能力只有：今日出席與預計接送（讀）、登記今日接送時間與接送人（寫，限當天 15:00 前）、當日活動紀錄（文字＋最多 6 張照片）、臨時通知（停課／提早接送／物品提醒，部分需回覆已讀）、回覆已讀。
- 登入：中心發的一次性簡訊連結，沒有帳密。
- 不存在：聊天、繳費、成長報告、推播通知。設計不得假造這些能力。
- 無品牌、logo、設計系統。
