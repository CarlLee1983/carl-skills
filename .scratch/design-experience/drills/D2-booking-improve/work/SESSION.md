# SESSION：毛毛日和 `/booking` 預約頁改善

## 任務與目標

- 專案：毛毛日和寵物美容官網（Next.js，已上線一年），頁面 `/booking`，commit `4e1a9c2`。
- 原始請求：「預約頁 /booking 常有客人打來說約不到，你幫我看看哪裡有問題、要怎麼改。」
- 進入模式：**Improve**。依據：介面已存在且上線，使用者不滿並要求改善。視覺來源：品牌 token（`styles/tokens.css`，見 `../fixtures/feature-first-project.md`）與品牌指南固定視覺；現況頁的樣式（4px 圓角、`#ccc` 邊框等）是頁面自訂，不屬品牌來源。
- 參考來源：無。
- 主要使用者（使用者陳述）：40–65 歲飼主，多用手機，新舊客都有。
- 工作重述：飼主用手機、在幾分鐘內替毛孩約到自己能到的美容時段，當場確定約成（拿到預約編號）。
- API（`../fixtures/feature-first-project.md`）：`GET /services`（名稱、時長、價格）、`GET /slots?date=`（一次一天）、`POST /bookings`（回傳預約編號，送出即成立）、`POST /bookings/{id}/cancel`（簡訊連結取消）。不存在：會員、登入、付款、評價、定位、AI。
