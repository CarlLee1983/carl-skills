# SESSION：寵物美容預約網站（店名暫定 PawLux）

## 任務與目標

- 原始需求：「想做一個寵物美容預約網站，想做成這張圖這樣（R1），配色和字體的感覺想參考這個網站（R2）。」
- 專案資料：`../fixtures/capabilities.md`（只有後端 API：`GET /services`、`GET /slots?date=`、`POST /bookings`、`POST /bookings/{id}/cancel`；無會員、登入、點數、付款、評價、美容師定位、AI；店名未定、無 logo）
- 起手方式：**主題起手**。依據：無前端、無品牌、無設計系統。
- 產品類型：品牌型首頁 + 預約流程（使用者 Q1 確認）。
- 主任務（已確認）：用手機的飼主，1 分鐘內完成預約、拿到預約編號；首個流程：首頁 → 服務 → 時段 → 資料 → 完成。
- 設計工作區：本目錄 `work/`。
